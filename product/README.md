# Underwriting IQ product workspace

Underwriting IQ is an independent portfolio project exploring agentic intelligence for automated life insurance underwriting. This repository contains sanitised product discovery evidence and public-facing case-study material.

**Current status:** Phase 1 — Internal Discovery Complete. Independent customer validation, market research, technical feasibility and willingness-to-pay validation remain outstanding.

The project does not publish applicant data, insurer identifiers, proprietary rules, premium loadings, confidential employer information or unsupported outcomes.
