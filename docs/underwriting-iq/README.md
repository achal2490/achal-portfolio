# Underwriting IQ

Independent portfolio project: Agentic Intelligence for Automated Life Insurance Underwriting.

Current status: Product Discovery in progress.

This directory is the source of truth for project assumptions, evidence, decisions, experiments, governance and publication history. It must not contain confidential employer information, real applicant data, proprietary underwriting rules or unverified outcomes.

## Working principles
- Separate planned work from completed evidence.
- Record assumptions and unresolved questions explicitly.
- Do not convert hypotheses into findings.
- Publish only inspectable artefacts and substantiated claims.

## Structure
- `master-plan.md` — scope, milestones and success hypotheses
- `discovery/` — discovery questions, evidence and synthesis
- `strategy/` — product strategy and business-case work
- `requirements/` — user journeys, requirements and acceptance criteria
- `architecture/` — agent and system design decisions
- `evaluation/` — experiment plans, evaluation sets and results
- `governance/` — risk, responsible AI and production-readiness work
- `delivery/` — delivery increments and release notes
- `commercial/` — positioning, packaging and go-to-market assumptions
- `decision-log.md` — material product and architecture decisions
- `learning-journal.md` — dated learning and reflection
- `publication-history.md` — portfolio updates
